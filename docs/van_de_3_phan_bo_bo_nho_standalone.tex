\section{Ngữ cảnh ngắn}
SOPWM cần hai lớp dữ liệu: (1)~LUT góc tĩnh theo $(N,m)$; (2)~bảng lịch CMP động cho DMA. Hai lớp này có ràng buộc vùng nhớ khác nhau --- phần dưới phân tích chi tiết.

\begin{equation}
  \text{Q1: } \theta_i = \alpha_i;\quad
  \text{Q2: } 180^\circ - \alpha_{M+1-i};\quad
  \text{Q3: } 180^\circ + \alpha_i;\quad
  \text{Q4: } 360^\circ - \alpha_{M+1-i}.
  \label{eq:quarter_expand}
\end{equation}
